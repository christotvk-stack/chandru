# ROAMRIDE

A responsive Indian travel and bike accessories storefront built with React and Vite. Prices are shown in Indian rupees (INR). The shopping experience runs entirely in the browser; cart, wishlist, account, and order data persist in `localStorage`.

## Run locally

```sh
npm install
npm run dev
```

Create a production build with `npm run build` and serve it with `npm run preview`.

## Demo flows

- Browse 40 travel bags, travel accessories, bike accessories, and camp accessories by category, search, rupee price range, and sort order.
- Save items to a wishlist, add products to the bag, adjust quantities, and remove items.
- Apply `ROAM10` at checkout for 10% off; shipping is free on orders of ₹10,000 or more.
- Create a local demo account with an email address, complete the India-first delivery and simulated card forms, and view order tracking in the account page.
- Open the store admin view from the account page or the footer. Its sales and order data are local to this browser.

Product photography uses Unsplash URLs with image fallbacks. No backend or external commerce services are required.
